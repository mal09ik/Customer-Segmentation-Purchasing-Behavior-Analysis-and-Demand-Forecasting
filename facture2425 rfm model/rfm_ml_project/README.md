# RFM ML Project

Professional skeleton for the invoice/RFM workflow.

## Structure

- `data/raw/`: original source data
- `data/processed/`: cleaned datasets ready for analysis/modeling
- `notebooks/`: exploratory and preprocessing notebooks
- `reports/figures/`: exported charts and visual outputs
- `src/`: reusable Python scripts/modules
- `models/`: trained model artifacts
- `configs/`: configuration files and parameters
